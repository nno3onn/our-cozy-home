# Illustrated pilot assets

This is the first finished visual set for the room redesign: a sunny room, rabbit and cat companions, and three reusable furniture sprites. All PNG files are transparent where they are rendered as sprites; the room is a full-scene background.

The catalog remains intentionally mixed during production: `cushion-shell`, `table-round-cookie`, and `plant-round-rubber-tree` use these finished assets, while the remaining catalog entries resolve through the same manifest with placeholders. This preserves the catalog, room, shop, and inventory contract while the rest of the art is commissioned or replaced.

Do not imply that placeholder entries are final production artwork. Asset status is surfaced in the development gallery.
