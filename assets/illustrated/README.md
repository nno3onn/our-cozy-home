# Illustrated pilot assets

The current finished furniture pilot set contains the shell cushion, cookie
table, round rubber tree, moon-sleep bed, firefly stand, soft oval rug, and
sunlight ribbon curtains. Every file is a transparent PNG used by both catalog
thumbnails and the room renderer.

The finished memory furniture pilot set contains the birthday table and picnic
radio; the remaining memory variants still use clearly labeled placeholders.

This is the first finished visual set for the room redesign: a sunny miniature dollhouse room, rabbit, cat, bear, and dog companions, three reusable shop furniture sprites, and one birthday memory-table sprite. The visual direction is a miniature dollhouse product set: compact rounded geometry, soft plush animal bodies, pale wood and muted pastel materials, and uncluttered isometric presentation. The three shop sprites are a low bouclé shell cushion, a pale-wood cookie-edge table, and a matte clay rubber tree; they deliberately avoid busy illustrated scenes and product-photo backgrounds. The room keeps its central rug open for four companion sprites; all other PNG files are transparent where they are rendered as sprites.

The catalog remains intentionally mixed during production: `cushion-shell`, `table-round-cookie`, `plant-round-rubber-tree`, and `memory-dining-table-birthday-table` use these finished assets, while the remaining catalog entries resolve through the same manifest with placeholders. Their renderer uses category-shaped miniature props rather than a generic colour block, but they remain placeholders rather than final artwork. This preserves the catalog, room, shop, inventory, and memory-furniture contract while the rest of the art is commissioned or replaced.

Do not imply that placeholder entries are final production artwork. Asset status is surfaced in the development gallery. New assets should use one clear object, limited materials, a simple silhouette, and no readable labels or decorative clutter.
