## 결정 기록

### 2026-09-19

- Expo, React Native, TypeScript와 Supabase로 신규 프로젝트를 구축한다.
- 별도 애플리케이션 서버 없이 중요 규칙은 PostgreSQL RPC 트랜잭션으로 처리한다.
- 집 정원은 4명이고 사용자당 활성 집은 하나다.
- Supabase 없이 실행되는 명시적인 데모 모드를 제공한다.
- 방은 Skia 기준 좌표와 고정 슬롯을 사용하며 일상 움직임은 기기에서 재생한다.
- 퇴장자의 참여 추억은 원본을 복제하지 않고 퇴장 시각의 열람 범위를 보존한다.
- 원작자 삭제는 퇴장자의 개인 보관함에도 적용한다.
- 재입주는 이전 viewer 권한이나 부재중 기록 권한을 되살리지 않는다.
- 모든 주요 화면에 빈 상태, 실패 상태와 불확실한 명령 결과 조정을 구현한다.
- 동물 두 종과 가구 한 테마로 시각 규칙을 먼저 검증한 뒤 전체 카탈로그에 적용한다.
- 완료는 화면 존재가 아니라 여러 실제 계정의 연결된 사용자 흐름으로 판단한다.

## 실제 환경 완료 시나리오

실제 Supabase 프로젝트가 준비되면 최소 두 계정 A와 B로 다음 결과를 기록한다.

1. A의 집 생성과 B 초대
2. B 입주와 양쪽 방 구성원 갱신
3. 두 사람의 추억 기여와 동일한 가구 확인
4. B 탈퇴와 집 데이터 접근 차단
5. B 개인 보관함의 퇴장 시점 스냅샷 확인
6. 퇴장 뒤 A의 추가 내용이 B에게 보이지 않는지 확인
7. A의 원본 삭제가 B 보관함에도 반영되는지 확인

딥 링크, 알림 권한·수신, 앱 종료 뒤 재실행과 이미지 업로드는 Development
Build를 설치한 실제 기기에서 별도로 기록한다.
