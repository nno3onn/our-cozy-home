# 에셋 목록 Foundation 정리 계획

## 목표

40종 상점 아이템과 15종 추억 가구를 검수하는 개발용 목록을 현재 Foundation UI와 반응형 규칙에 맞춘다.

## 구현 순서

1. 넓은 화면의 4열, 좁은 화면의 안전한 1열, 단일 뒤로가기와 접근 가능한 상태 배지를 테스트로 고정한다.
2. 기존 장식형 `Panel`과 호환 색상을 의미 기반 표면·테두리·상태 색상으로 교체한다.
3. `AppPageHeader`, 요약 안내, 반응형 그리드를 적용하고 55종 카탈로그가 누락 없이 표시되는지 검증한다.
4. 제품 작업 현황과 디자인 결정을 갱신하고 정적 검사 및 웹 빌드를 실행한다.

## 제외 범위

- 카탈로그 데이터와 에셋 파일 자체의 변경
- 일반 사용자에게 개발용 화면을 공개하는 변경
- 상점·보관함 구매 및 배치 규칙 변경
