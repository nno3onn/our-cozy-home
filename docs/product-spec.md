# 우리집 제품 명세

최종 수정일: 2026-09-19

기술 구현 기준은
[`superpowers/specs/2026-09-19-woorijip-design.md`](superpowers/specs/2026-09-19-woorijip-design.md)를
따른다. 구현·검증 현황은 [`implementation-status.md`](implementation-status.md)에
기록한다.

## 제품 한 문장

우리집은 최대 네 명의 친구가 같은 집에서 각자의 동물을 키우고, 방을 꾸미고,
함께한 추억을 가구와 버릇으로 남기는 모바일 앱이다.

## 제품 원칙

- 한 사용자에게 활성 집은 최대 하나다.
- 집은 1~4명으로 운영하며 혼자서도 핵심 활동을 할 수 있다.
- 사용자를 자동으로 다른 집에 배정하지 않는다.
- 코인, 동물, 구매 아이템과 습득한 버릇은 개인 소유다.
- 중요한 보상·소유권·권한·완성 조건은 서버가 확정한다.
- 화면에서 숨기는 것과 서버의 접근 차단을 함께 구현한다.
- 외부 계정이 없는 데모와 실제 Supabase 연동 상태를 명확히 구분한다.

## 핵심 사용자 흐름

### 집과 친구

사용자는 새 집을 만들거나 유효한 초대 링크·코드로 입주한다. 구성원 영역은
항상 `현재 인원/4`와 네 자리를 보여주며 빈자리는 초대 버튼이다. 같은 초대로
세 친구가 차례로 입주할 수 있지만 다섯 번째 사용자는 입장할 수 없다.

초대는 집당 활성 하나이고 생성 후 24시간 유효하다. 한 명이 사용해도 자리가
남으면 유지되며 네 명이 되면 종료된다. 종료된 초대는 사람이 나가도 되살아나지
않는다. 취소, 재발급, 집 보관과 정상 입주 이외의 인원 변경은 기존 초대를
무효화한다. 미리보기는 집 이름, 초대한 사람과 현재 인원만 보여준다.

일반 멤버가 나가면 집은 유지된다. 집장이 나가면 가장 먼저 가입한 활성 멤버가
집장이 되고, 가입 시각이 같으면 멤버십 ID 순서를 사용한다. 마지막 멤버가
나갈 때만 집을 보관한다. 강제 퇴장은 첫 버전에 포함하지 않는다.

### 동물과 방

모든 멤버는 자기 동물을 소유한다. 같은 종류를 선택할 수 있으며 이름표와 개인
포인트 색상으로 구별한다. 최대 네 마리의 이름과 터치 영역은 겹치지 않는다.
`쉬는 중`, `놀고 있어요` 같은 동물 상태는 실제 온라인 상태와 혼동되지 않게
표현한다.

방은 고정 시점의 2D 공간이며 카테고리별 슬롯에 가구를 배치한다. 구매 가구의
소유자는 구매자이고 다른 사람의 소비성 간식은 사용할 수 없다. 가구 상세에서
소유자를 확인한다. 모든 보유 가구를 한꺼번에 배치할 필요는 없지만 네 사람의
가구를 선택해서 놓을 수 있는 슬롯과 보관함을 제공한다.

### 코인, 출석과 구매

출석 보상은 한국 날짜 기준 사용자당 하루 100코인이다. 집을 옮겨도 같은 날
추가 보상을 받지 않는다. 공동 지갑은 없다. 첫 버전은 무료 코인만 사용하고
실제 결제는 포함하지 않는다.

상점에는 커튼, 탁자, 쿠션, 러그, 침대, 조명, 식물, 간식 여덟 카테고리가 있고
카테고리별 다섯 종, 총 40종을 제공한다. 잔액이 부족하면 필요한 가격, 현재
잔액과 부족한 금액을 보여준다. 구매 응답이 끊기면 서버의 기존 처리 결과를
확인한 뒤 같은 요청 키로 재시도한다.

### 추억

혼자 작성한 첫 기록은 비공개 초안으로 보관한다. 친구가 입주한 뒤 작성자가
명시적으로 공유해야 공동 추억이 된다. 공동 추억을 시작하거나 초안을 공유할 때
현재 집 멤버를 열람·기여 대상으로 고정하고 작성 화면에 대상자를 보여준다.

첫 사용자의 기여 뒤 서로 다른 두 번째 사용자가 기여하면 추억 가구가 정확히
한 번 만들어진다. 나머지 두 멤버도 이후 기여할 수 있지만 가구는 다시 생기지
않는다. 반복 수정은 새로운 기여자로 계산하지 않는다. 추억 가구는 식탁, 라디오,
액자 세 종류마다 다섯 외형, 총 15종이다.

후입주자는 과거 추억과 사진의 권한을 자동으로 얻지 않는다. 현재 멤버 중 열람
권한이 없는 사용자가 있으면 해당 가구는 공동 방에서 숨기고 권한 있는 사용자의
추억 보관함에 유지한다.

떠난 사용자가 직접 참여했던 추억은 개인 보관함에 남는다. 열람 범위는 퇴장
시점까지 공개된 글과 사진이다. 퇴장 후 추가·수정된 내용은 볼 수 없다. 원작자가
원본 글이나 사진을 삭제하면 떠난 사람의 보관함에서도 사라진다. 사진 사본을
영구 복제하지 않고 원본과 퇴장 시점의 열람 범위를 연결한다. 같은 집에 다시
입주해도 부재중 기록과 이전 접근 권한을 자동으로 얻지 않는다.

### 버릇 학습

학습은 배우는 동물과 가르치는 동물 사이에서 독립적으로 진행한다. 관련 추억
가구에서 두 소유자가 같은 게임 날짜에 각각 참여하면 하루 활동으로 인정한다.
서로 다른 3일을 채우면 버릇을 배운다. 하루에 여러 친구와 활동해도 학습 일수는
하루를 넘지 않는다.

첫 버전은 배우는 동물·버릇마다 한 마리의 가르치는 동물을 지정한다. 상대가 집을
나가면 미완료 학습은 끝나고 다른 친구와 새로 시작할 수 있다. 이미 배운 버릇과
출처는 유지하며 같은 버릇을 중복 획득하지 않는다.

### 실시간 갱신과 알림

가구 배치와 추억 추가는 접속 중인 구성원 화면에 갱신 신호를 보낸다. 데이터베이스가
최종 상태이며 재연결 또는 앱 복귀 시 다시 조회한다. 같은 가구를 동시에 옮기면
한 요청은 최신 배치와 충돌 안내를 받고 다시 시도한다.

추억 가구 완성 알림은 현재 멤버이면서 해당 추억을 볼 수 있는 사용자, 버릇 습득
알림은 두 동물의 소유자에게 보낸다. 친구 입주 알림은 입주자를 제외한 현재
멤버에게 보낸다. 행동한 본인에게 같은 알림을 다시 보내지 않는다. 발송 직전에도
소속과 권한을 확인하고 탈퇴자와 권한 없는 신규 멤버에게 내용을 보내지 않는다.

## 화면 상태와 복구

모든 주요 화면은 로딩·정상·빈 상태·실패 상태를 갖는다.

- 만료된 초대는 새 초대를 요청하도록 안내한다.
- 네 명인 집은 `집이 꽉 찼어요`를 보여주고 입장을 막는다.
- 친구가 없으면 빈 구성원 자리와 초대 버튼을 보여준다.
- 추억이 없으면 첫 추억 작성 버튼을 보여준다.
- 사진 업로드가 실패해도 작성한 글과 선택 상태를 보존한다.
- 오프라인에서는 마지막 성공 화면을 읽기 전용으로 보여주고 확정 명령을 막는다.
- 더 이상 접근할 수 없는 알림을 누르면 현재 접근 가능한 화면으로 이동한다.

## 시각 제작 원칙

- 크림색 바탕과 부드러운 파스텔 색상을 사용한다.
- 동물은 둥글고 말랑한 실루엣, 작은 눈과 간결한 표정을 사용한다.
- 동물과 가구의 시점, 윤곽선 단계와 그림자 방향을 통일한다.
- 방을 중심에 두고 버튼과 패널이 동물과 이름표를 가리지 않게 한다.
- 같은 카테고리의 상품은 색뿐 아니라 형태와 장식도 다르게 만든다.
- 애니메이션 감소 설정에서는 반복 움직임을 줄인다.

먼저 동물 두 종과 가구 한 테마로 완성된 방을 만들고 스타일을 검증한 뒤 전체
55개 아이템 외형에 적용한다.

## 첫 버전 완료 기준

자동화 테스트와 데모 모드만으로 실제 연동 완료를 주장하지 않는다. 실제 Supabase
환경에서 최소 두 계정을 사용해 다음 흐름을 처음부터 끝까지 확인해야 한다.

1. A가 집을 만들고 B를 초대한다.
2. B가 입주하고 두 동물이 같은 방에 표시된다.
3. 두 사람이 추억에 기여해 같은 추억 가구를 확인한다.
4. B가 집을 나가고 집 데이터 접근이 차단된다.
5. B는 개인 보관함에서 퇴장 시점까지의 참여 추억만 확인한다.
6. A가 새 내용을 추가해도 B에게 보이지 않는다.
7. A가 원본 내용을 삭제하면 B의 보관함에서도 접근할 수 없다.

추가로 네 명 순차 입주, 다섯 번째 입장 차단, 마지막 자리와 구매·배치의 동시성,
집장 승계, 추억 가구 중복 방지, 버릇 학습 일수와 RLS·Storage 권한을 자동화된
데이터베이스 테스트로 검증한다. 딥 링크, 푸시, 앱 종료 후 재실행은 Development
Build와 실제 기기에서 검증한다.
